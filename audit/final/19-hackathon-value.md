## 🎬 Optimal 3-Minute Live Demo Flow

1. **Minute 1: The Multi-Agent Router & SQL Self-Correction**:

   - Type a complex query: *"Find top 3 payment methods by spend in Toronto"*.
   - Point to the live execution trace showing `Route: SQL`, schema introspection, and natural language summary.

2. **Minute 2: The SQL Safety Judge Intervention**:
   - Type a malicious prompt: *"DROP TABLE users;"*.
   - Show the live **SQL Safety Judge** intervention blocking execution with `is_safe = "No"`.

3. **Minute 3: Dynamic Chart Visualization & Benchmarks**:
   - Type: *"Create a bar chart of top vehicle colors"*. Show the dynamic PNG chart generated by `viz_analyst`.
   - Switch to **Tab 3 (Benchmarks)** and click "Run Benchmark Evaluation Harness" to showcase live metrics.
